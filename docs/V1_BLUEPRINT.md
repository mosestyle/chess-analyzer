# V1 Blueprint

## Primary: Analyzer

PGN/FEN import → Stockfish 18 Full NNUE/Lite → evaluation and top lines → full Game Review → accuracy → classifications → critical moments → explanations → Show Best → Retry → evaluation graph.

## Secondary: Play vs Computer

Levels 1–12 → White/Black/Random → Practice/ Casual → hints/takebacks → fast local Stockfish responses → post-game **Analyze This Game**.

## V1 screens

1. Home
2. Analyze / Import
3. Analysis progress
4. Game Summary
5. Game Review
6. Play Computer setup
7. Play Computer board
8. Settings
9. About / licenses

## Product principles

1. Analyzer first.
2. Explain, do not merely score.
3. Local-first and privacy-friendly.
4. Same responsive codebase for desktop, tablet and mobile.
5. Keep engine/analysis logic separate so native Android can follow later.

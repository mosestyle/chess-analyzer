# Classification specification — V1

Main labels:

- Brilliant
- Great
- Best
- Excellent
- Good
- Book
- Inaccuracy
- Mistake
- Miss
- Blunder

Special tags are separate and may coexist with a main label:

- Critical Moment
- Only Move
- Forced Move
- Missed Win
- Missed Mate
- Missed Tactic
- Winning Sacrifice
- Hanging Piece
- Major Turning Point

## Brilliant / Great

V1 deliberately keeps Brilliant uncommon. It requires the played move to match Stockfish's best move and uses a candidate sacrifice test plus a meaningful gap to the second line. Great requires the best move plus a meaningful alternatives gap.

This is a starting heuristic, not a claim to reproduce Chess.com's definitions.
